# FRCC-CS-Coursework

This repository contains weekly coding assignments and foundational algorithms completed during my Computer Science degree program at Front Range Community College. Rather than creating separate repositories for every small assignment, I have consolidated my weekly coursework here to document my ongoing progression in software engineering.

## Concepts Covered
* Object-Oriented Programming (OOP)
* Data Structures (Multi-dimensional Arrays, Linked Lists, Queues)
* Algorithm Design & Logic
* Exception Handling & Debugging
* Graphical User Interfaces (GUI) and Java Frames

**Language:** Java
